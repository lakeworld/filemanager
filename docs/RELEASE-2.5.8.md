# 启禾文件管理 v2.5.8 发布说明

> 版本：2.5.8 · 2026-09-13 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> **09-14 补丁**（版本号不变，安装包重出）：修掉「弹窗开着时按键归属」一族缺陷——预览里按 `Delete` 删的终于是你正在看的那一张，弹窗里按 `Ctrl+C` / `Ctrl+A` / `Delete` 不再被底下的列表抢走。详见 §四 最后一条与 §六 的边界说明。
> 本版为 **体验补齐 + 界面统一** 版：预览可以连着看了，复制/粘贴/剪切三个键全站能用，弹窗·按钮·输入框·下拉框换成同一套材质，设置页多了 5 个可选开关。

---

## 一、预览能连着看了

- **一处开、整列可翻**：预览弹窗支持 **← / → 方向键**与画面两侧的 **◀ ▶ 按钮**，在**打开那一刻看到的那一列文件**里循环切换，标题旁显示位置（如 `3 / 12`）
- **覆盖全部入口**：文件浏览器、图包库、证书库、全局搜索、发票/入库台账、报价台账与报价文档、仪表盘"最近文件"、批量识别的待确认区与已选清单——都按**当前筛选/排序结果**翻页
- **到头绕回**：最后一张再按 → 回第一张（与主流看图器一致）
- **不打架**：在预览里打字时方向键只动光标；视频里方向键仍归视频自己调进度；右键菜单或删除确认开着时不抢键
- **PDF 能跳页**：预览 PDF 时工具条上有页码框，输入数字回车直达

## 二、复制 / 粘贴 / 剪切补齐

- **复制有回声**：以前同一个动作在不同地方三种表现（有的提示、有的静默、右键复制成功了也不吭声），现在统一为「已复制 N 个文件到剪贴板」，失败明确告知
- **Ctrl+C 从 1 个页面变成 8 个列表**：文件浏览器、图包库、证书库、笔记库、搜索、发票台账、入库台账、报价列表都能复制选中的文件；发票/入库/报价三处批量工具条各补「📋 复制」按钮
- **Ctrl+V 能粘进来了**：在资源管理器里复制几个文件，切到本应用的**具体文件夹页**按 `Ctrl+V` 即导入，命名模板、重名加序号、缩略图与拖拽导入完全一致
- **Ctrl+X = 应用内移动**：选中按 `Ctrl+X`（卡片变半透明），到目标文件夹按 `Ctrl+V` 搬走，不用"先复制再删原文件"；`Esc` 或改选别处即撤销标记。**外发永远用「复制」**——把文件剪切到应用外会把文件移出工作区、断掉元数据与台账引用
- **该让位时让位**：在输入框/笔记正文里打字、或正文选中了一段文字时，这三个键仍归文本编辑（可在「设置 → 常规」关掉那条让位开关）

## 三、界面全站统一（本版最大的一块）

- **弹窗一个模子**：统一「标题 + 一句说明 + 右上关闭」头部、字段区、底部动作条三段骨架；必填字段带红色 `*`；表单两列排布不再挤成窄缝
- **按钮不再各写各的**：全站 269 个按钮里 258 个进了统一清单，**凡挂实体底色的按钮 100% 有按压反馈与悬停过渡**（此前 147 个各写各的、其中 79 个连悬停都是瞬变）；另立三个"形状档"给文字链接式、纯图标小圆钮、整行可点的列表项——只统一节奏，不统一尺寸与颜色
- **输入框与多行框统一**：手搓边框/圆角/内边距的那批换成统一底座
- **下拉框换成可搜索下拉**：全站原生 `<select>` 收口，长列表可输入过滤；并修掉两处行为（再点已选项不重复触发筛选；禁用态下键盘也改不动值）
- **下拉菜单不再"飘"到别处**：靠近窗口右边缘或下边缘的下拉框（工具栏右侧的筛选器、弹窗里的下拉最容易中招），以前菜单会算到控件左上方老远的空处；现在按菜单的实际大小定位，常态紧贴控件正下方，真放不下才翻到上方
- **图标不再看系统装了什么字体**：侧栏、卡片、按钮上的图标以前借用系统的 emoji 字体来画，遇上没装 emoji 字体的系统（精简过的 Windows 尤其常见）就整块变成空白，严重时把同一行的文字挤成竖排。现在图标随应用自带一份（只收录用到的 47 个图形，约 62KB），系统有没有那套字体都长一个样；`◀` `▶` `⚠` 这类本该是文字样式的符号仍按正文颜色显示（黑色），不会被染成彩色
- **多选悬浮操作条单点化**：以前 7 个页面各有一份副本、表现不一致，现在共用一套
- **壳层玻璃化**：侧栏与顶栏换成统一的半透明材质层次

## 四、快捷键与设置页

- **快捷键统一收口**：全站快捷键注册点收敛为单点，设置页新增**快捷键速查**表
- **弹窗开着时不再误伤（09-14 补丁）**：以前在预览里按 `Delete`，删的是**底层列表选中的另一个文件**（确认框只说「删除选中的 1 个」，不写文件名，而屏幕上你只看得见预览那张）；表单弹窗里只要焦点不在输入框（点过按钮/标题/空白就算），`Ctrl+C` 会被底层抢去复制文件、`Ctrl+A` 会把底下列表多选、`Delete` 会在弹窗上再叠一层删除确认。现在这三类键在弹窗开着时都不再去动列表，预览里 `Delete` 删的就是眼前这一张（仍走二次确认）。**输入框里的复制粘贴本来就正常，也没改**；**右键菜单 / 日期选择 / 可搜索下拉这类小浮层不算弹窗**——把它们当弹窗会把「`Ctrl+X` 剪切 → 换文件夹 → `Ctrl+V` 移动」这条主路径一起挡掉；**没有弹窗时 `Delete` 的语义一字未改**
- **新增 5 个开关**（默认值 = 升级前的行为，不点就等于没变）：关闭窗口后留在托盘 / 自动检查更新 / 悬浮多选操作条 / 剪贴板复制保护 / 证书到期提醒（30 / 14 / 7 天）
- 开关改动**只在你真的动过之后才写进配置文件**

## 五、正确性与稳定性

- **重名文件不再「叠罗汉」**：同一文件夹连续放入同名文件，以前会得到 `X.jpg` → `X_1.jpg` → `X_1_2.jpg`（第 4 次更离谱），现在固定 `X.jpg` → `X_1.jpg` → `X_2.jpg`。危害不只是难看：文件名里的 `_` 是产品编号分隔符，`_1_2` 会被误读成编号出了两次，排序也会跳序。覆盖全部会自动改名的入口（导入、移动/复制、入库、发票、报价、交换区收取、证书与文档归档）
- **开机自启不再弹出「陌生的 Electron 窗口」**：修掉托盘常驻那条路径上的启动竞态
- **Windows 上「点仪表盘不跳转」根治**：生产模式改走 hash 路由（file:// + 路径型路由在 Windows 盘符语义下双重失效）
- **证书/文档导入硬链接去重**：同一份内容在多处归档时按硬链接共用磁盘块，配套巡检会把断链的重新接上
- **仪表盘"最近文件"删除后不刷新**、**工作区下拉菜单点空白不收起**、**移动对话框默认停在第一个子文件夹**这三处小毛病一并修掉
- **界面走查从 25 张扩到 40 张**（含 1024 / 900 / 768 三档窄窗口 × 证书库 / 设置 / 笔记库九张），卡片阴影与勾选框着色做过像素级核对

## 六、本版明确未做与限制（避免误会）

- **列表键盘导航**（`Enter` 打开 / 方向键移动选中）**未做**——本批未纳入范围（09-14 注：`Delete` 删除选中与 `Ctrl+A` 全选**是有的**，但只在「选中后底部浮条出现」时生效；聚合页如产品集总览、客户列表按 `Ctrl+V` 不做声，那里"该放进哪个文件夹"没有唯一答案，请用「导入文件」）
- **剪贴板里是图片位图**（截图工具直接复制）时的 `Ctrl+V` 落成 PNG **未做**，另立项
- **「减少动画」开关没做**：与上一轮定下的「动画降级全站单点」那条自动检查直接冲突（要做开关就得在样式里开第二条路径），改规矩需要单独决策
- **动效中间帧、托盘图标、高 DPI、触摸板手感、`Ctrl+Alt+K` 是否与系统快捷键撞车**仍需真机目测——自动截图工具只能在动画结束后取帧
- **图标随包字体这一项在真 Windows 上仍未目测**：本项目的 Windows 测试环境（wine）加载不了任何随包字体——连上一版就在用的中文字体也一并报失败，属环境上限，不能拿它当字体验收。真机上请目测三件事：侧栏与卡片的图标齐全、`◀` 是黑色不是彩色、没有任何一行文字被挤没。已列入发布前的人工清单
- **Windows 侧一项如实说明**：`Ctrl+V` 粘贴导入依赖的系统剪贴板**读**通道（PowerShell `Get-Clipboard -Format FileDropList`）在本项目的 Windows 测试环境（wine）里无法验证——wine 的 `powershell.exe` 不执行任何 cmdlet。该通道在 Linux 侧有端到端实证，Windows 侧目前只有单元级覆盖，真机验证已列入发布前的人工清单
