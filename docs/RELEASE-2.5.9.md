# 启禾文件管理 v2.5.9 发布说明

> 版本：2.5.9 · 2026-09-22 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版是 **加固 + 两处真功能** 的一版：门禁从"长期红等于没有门禁"回到真的会拦人，另加一个**计算台账**（工作区第四类对象「算」）和一处**子文件夹改以硬盘为准**（起因是用户直报的"删一个文件夹牵动全身"）。

---

## 一、计算：工作区里多了「算」这一类（本版最大的一块）

- **侧栏「工具 → 计算」**，也可以按 `Ctrl+=` 随时唤起一个**悬浮面板**（`Esc` 或点面板外即关）。
- **敲算式回车记一条**：四则、括号、百分号、日期都收——`(3200 + 380) * 1.15` 这类手边账直接敲；日期也算：`2026-09-16 + 60` 得 `2026-11-15`，两个日期相减得天数（`日期 × 2` 这种没有业务意义的组合**如实报错**，不猜）。
- **每条都留得住**：算式、结果、时间成一条历史，点算式**回填改着再算**（在原式上接着算，计算链自然形成），点结果即复制；每条还能加标题与备注。
- **「暂存」和「已存资料」两态**：随手敲的是暂存，觉得有用就转正；两种都写进工作区、**跨重启不丢**（是台账，不是用完即弃的系统计算器）。
- **纯本地**：零网络、零账号、不碰任何云服务；数据住在工作区的 `.qihefilemanager/calcs.json`，跟着工作区走。
- 删一条 = **直接删 + 二次确认**：计算条目没有盘上的文件，不进回收站。

## 二、子文件夹改为「以硬盘为准」：删一个不再牵动全身（A9）

- **起因**：用户直报「删掉某个产品集的文件夹，别的产品集/聚合页跟着一起不显示」。根因是那张"全站子文件夹模板表"写在删除路径上被改写；本版把**读取侧改成以盘为准**、**写入侧根除顺带改写**。
- **名单由硬盘决定**：产品集 / 客户 / 供应商的文件区 tab、产品集卡片的文件夹行、证书库与图包库的聚合面，一律看盘上实际有什么（空目录淡一档显示）。
- **新建子文件夹不再顺手写进那张全站模板表**；要改默认集就去「设置 → 子文件夹」——那里现在是那张表的**唯一入口**。
- **改名分两个入口**：默认**只改眼前这一个实体**；要动整个工作区的盘，得在改名弹窗里**显式点名**（红色 ⇌）。"改一处、全站跟着动"不再默认发生。
- **实体页右键子文件夹「就地改名」**：只改这一个实体的盘上目录，别的产品集/客户不受影响。
- **老工作区体检**：打开设置页即可看到「模板表 vs 盘上实际」的**差额清单**（只读，不自动改任何东西），方便老工作区对齐。

## 三、搜索与跳转这几处不再白费工夫（A6）

- **顶部多了「← 后退」**：以前从搜索结果点进一个产品集，想回到结果列表得把关键词重新搜一遍；现在搜索结果会留在地址里，点「← 后退」就回到**带着原关键词**的结果页。
- **新建完产品集直接落在那个产品集里**，不用再回列表翻找它。
- **`Ctrl+Alt+S` 一键唤醒搜索**（默认关，需在「设置 → 通用」里打开「全局唤醒搜索」）：不管窗口是藏着还是被别的窗口盖住，按下去就会唤出主窗口并聚焦搜索框。默认关是因为它会占用你系统里的这个组合键；**被别的软件占用时设置页会如实显示「被占用」**，不会装作开着。

## 四、不用去网页也能注册账号了（A8）

- **注册整条链搬进应用内**：填邮箱 + 密码（至少 8 位）→ 我们发一封带 **6 位数字验证码**的邮件（5 分钟内有效）→ **在应用里把码填进去就完成验证并自动登录**，不用再去官网页面、也不用去邮箱里点链接。
- **登录框支持图形验证码**：填了会带上，**不填照样能登录**（这一步是纯加法，不影响老用户）。看不清那张图？直接点它换一张；登录失败时也会自动给你换一张新码。
- 忘记密码仍然在官网重置（应用内不改密码）。**服务端尚未强制图形码**（切换随下一版），本版只是客户端先行。

## 五、修掉的两处"用着难受"

- **改信息弹窗里的标签，终于能翻到底了**：标签一多（超过约 7 个），在下拉里往下滚的**第一下就把整个下拉关掉了**，排在后面的标签根本选不到。现在面板内滚动不再自杀；键盘 `↑/↓` 选到第几条，那一条就一定被带到视野里。
- **右键菜单不再「闪一下就没」**：菜单留下过一个隐形菜单挂在页面上，之后每次开菜单都先撞上它（就地改名时最明显）。根因已修，菜单打开瞬间的无关滚动也不会再把它关掉。

## 六、插件协议增量（只增不改）

- **`commands[].openPage`**：插件的右键命令可以声明「去插件自己的页面处理」，宿主点击时把本次选中的文件**交接**给插件页面（`sessionStorage` 交接键 + 事件广播）。登记期三边校验（非空字符串 / `'/plugin/'` 前缀 / 必须命中本插件已声明的页面路径），**禁止越权跳转**。
- 未声明 `openPage` 的命令行为**一字未改**，旧插件零影响。公开契约见 `docs/PLUGIN.md`（rule10 + 运行语义段）。

## 七、工程与发布链（你用不到，但决定你能多快拿到修复）

> 本版立项的直接原因：`master` 的 CI 曾连续 4 轮红、跨 13 天且中间发过一次正式版——**门禁长期红等于没有门禁**。这一版把它治回"真的会拦人"。

- **版本一致性自检上线**：安装包版本号、更新日志、README 徽标、发布说明、安装教程多处必须同源，不一致就**不出包**（此前"版本号四处漂移"真出过一次事故）。
- **CI 补齐四道本地一直有、CI 从不跑的门禁**；崩溃取证管道现在真的会执行并留档。
- **修掉两处"看着绿其实没审"**：历史泄漏门禁在 CI 浅克隆下只扫 1 个提交仍报通过（现在**拒绝执行**而不是假通过）；崩溃 trace 在 CI 上压根没上传。
- **一条长期"本机绿、CI 红"的间歇性红完成定责**：不是环境抖动——`suppliers` 那条是测试少了一次轮询；`clipboard-guard` 那条是测试自己的夹具竞态（此前"负载型抖动"的定性作废）。
- **测试卫生**：修掉一条"日历一走就红"的用例；性能探针改成多次取样判 p90，不再被单次抖动误判；取证类复现 spec 转正为常驻规格（不再每天白跑）。

## 十、归位与下载口径

- **发布包归位**：`软件发布包/2.5.9/`（`deb/` + `win/`，含安装教程与截图）。该目录在坚果云内、自动同步，是发布包的**可重造源头与灾备源**；按惯例**只留当前版 + 上一版**（更旧的版本目录在每次发布归位时清理）。
- **官网下载通道（2026-09-13 起）**：下载按钮走自有服务器直链（图形码 + 一次性票据 + 同 IP 校验，`X-Accel-Redirect` 出字节），上传与 `version.json` 校验和由 `publish-box-installer.sh` **现算**、人不参与。
- **服务器只收两件**：Linux `.deb` 与 Windows `启禾文件管理 Setup <ver>.zip`（裸 `.exe` 不再下发——浏览器安全下载保护会拦；**AppImage 与便携 zip 不再上传服务器**，只在坚果云发布包内保留）。
- **Windows 裸 exe 不入发布目录**：NSIS 产物先压成 zip 再入包（坚果云同步会给裸 `.exe` 追加后缀，用户拿到手不能直接运行）。

## 十一、本版明确未做与限制（避免误会）

- **计算面板两处已知观察**（待用户拍板，未改）：① 面板带遮罩，点侧栏会"先关面板"而不是切页；② 面板刻意未标 `modal`，焦点不在输入框时按 `Delete` 可能作用到底层浮选条。**v1 不做「账物挂靠」**（计算条目关联到某张发票/产品集）——按冻结规格，本版只做"能算、能留、能转正"。
- **子文件夹改名"动全工作区"仍有入口**（红色 ⇌ 显式点名），只是不再默认发生——这是刻意保留的能力，不是遗漏。
- **全局唤醒搜索 `Ctrl+Alt+S` 在 Wayland 会话下可能不生效**（系统级热键的平台差异），X11 实测可用；与输入法/系统快捷键是否撞车需真机目测。**请把「设置 → 通用」里的开关当"可选加速器"**，不用它也能从侧栏进搜索。
- **图形码能否看清、邮箱验证码真能收到**需真机人眼核对（AI 无图像判读能力）；服务端强制图形码**未切**（随下一版）。
- **Windows 侧两项如实说明**（与上一版同源，未变）：① `Ctrl+V` 粘贴导入依赖的系统剪贴板**读**通道在本项目的 Windows 测试环境（wine）里无法验证——wine 的 `powershell.exe` 不执行任何 cmdlet，该通道在 Linux 侧有端到端实证、Windows 侧只有单元级覆盖；② 随包图标字体在 wine 下加载不了任何字体，真机仍需目测三件事（图标齐全、`◀` 是黑色、没有一行文字被挤没）。均已列入发布前的人工清单。
- **列表键盘导航**、**剪贴板位图 `Ctrl+V`**、**万文件首屏/缩略图专项**、**插件页面材质对齐**仍不在本版范围（各有归属，见仓库内部计划）。

## 十二、遗留

- CI 侧 `if: always()` / `if: failure()` 的连坐语义只能真 run 结：本版修好的两条（A1b 守卫、A1c 报告空传）已在本地做等价验证，**最终判据 = push 后 GitHub run 结论**。
- `check:version-sync` 的教程腿在本版归位后开始生效（本版目录 + 母本教程里的版本字面量必须等于 2.5.9）。
- 2.5.8 的同号补丁（09-14 弹窗按键归属）已在本版之前单独发布，本版**不重复**该内容。
