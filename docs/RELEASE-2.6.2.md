# 启禾文件管理 v2.6.2 发布说明

> 版本：2.6.2 · 2026-09-26 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版是 2.6.1 的**单点修正版**：修好工作区切换列表「名字被挤没、整行都成了『设为默认』」的布局塌陷。除这一处，其余与 2.6.1 完全一致。

---

## 一、工作区切换列表修好了：名字回来了，点哪儿就是哪儿

- **名字恢复显示**：顶栏「工作区」下拉里的「最近工作区」，此前每一行的名字被挤成 0 宽（看不见），行内只剩重复的「设为默认」；现在名字正常显示，右侧「设为默认 / 取消默认」回到它该在的位置。
- **点击面回到正确位置**：此前整行的点击区都落在「设为默认」上（想点名字切工作区，实际点的是设默认）；现在**点名字 = 切工作区，点右边 = 设默认**，与看到的完全一致。
- **「默认」标记不再叠字**：当前工作区那行的「默认」标记此前与「取消默认」叠在一起印成重影，现在各就各位。

## 二、升级方式

- 已装 2.6.1 的 **Windows 安装版 / Linux AppImage 版**：应用内「检查更新」会收到本版（也可从官网重新下载）。
- **deb 版**：官网下载页重新下载安装（就地升级，数据不受影响）。

## 三、已知限制（如实）

- 与 2.6.1 相同：Linux deb 不支持应用内自更新；官方插件目录 / 取钥 / 云能力需在应用内登录；Windows 真机链与双机局域网矩阵仍属人工验收项（本版以 wine 冒烟与自动化面替代取证）；插件页详情截图素材尚未随版上线（官方目录如实留白）。
- 本版**不含新功能**；直接装本版即涵盖 2.6.1 的全部内容（见 `CHANGELOG.md` v2.6.1 段）。
