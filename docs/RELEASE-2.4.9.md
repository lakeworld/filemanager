# 启禾文件管理 v2.4.9 发布说明

> 版本：2.4.9 · 2026-08-12 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版为 **v2.4.8 之上的功能版本**：供应商台账+目录、报价单（对齐客迹 Quotation）、开机自启、客户字段对齐客迹/仓迹（为 v2.7 erp-bridge 铺路）、命名模板编号槽位、日志系统 + 一轮用户实测打磨。

---

## 一、新功能

### 1.1 供应商管理

- 台账 + `供应商/<名>/` 目录（固定子文件夹：合同/对账单/往来文件）+ 列表/详情页 + 文件区
- 入库单表单「供应商」下拉关联（`supplier_id`，兼容自由文本）；供应商删除进回收站（`kind='supplier'`），重命名级联更新入库单引用
- 新建弹窗补标签输入；详情档案卡可「关联产品集」（core link/unlink + 校验产品集存在，为后续 AI 采购分析铺路）

### 1.2 报价单

- 台账对齐客迹 Quotation：明细行 + 汇总 + 三态状态机（草稿→已确认→修订中→草稿；已确认明细锁定）
- `报价/<YYYY>/` 原件归档 + 报价单号自动生成（`QT-YYYYMMDD-序号`，可手输覆盖查重）
- 客户详情报价联动（改名级联/删除灰显）；列表筛选（状态/客户/日期范围）+ `?status=` URL 预选（仪表盘草稿报价跳转直达）

### 1.3 开机自启

- 设置页「通用」开关；`--autostart` 启动延迟建窗、托盘常驻（不占渲染进程内存）
- Linux `.desktop` 自启项含全量生产参数（参数三处同步由单测锚定）

### 1.4 客户对齐客迹/仓迹（为 v2.7 erp-bridge 铺路）

- `CustomerInfo` 新增 `type/phone/email/address`（type 枚举「企业/个人」）；新建弹窗即可填写；列表支持类型筛选
- `erp_ext` schema 定稿 + 归属规则修订（erp-bridge 可写对齐字段与 erp_ext，box 专属字段 ERP 只读）

### 1.5 命名模板编号槽位

- 命名模板引擎新增 `sequence` 槽位（新工作区默认 产品集_子文件夹_原文件名_序号，导入按批次顺序补零）
- 批量重命名对话框复用命名模板（删前缀输入框、留起始序号）；设置页命名模板 card 可勾选 4 字段

### 1.6 日志系统

- 主进程日志核心迁入 core（node 直测）+ 容量上限 20MB 自动清理 + 14 天保留双保险
- 渲染进程 console.error/warn 转发落盘；「我的」页日志卡片（导出日志 zip，手动发送）

## 二、打磨轮（2026-08-12 用户实测反馈修复）

- **侧边栏重组**：13 项入口归为 5 组（概览/资料-产品/资料-业务/工具/系统）+ 组标题折叠
- **搜索引导**：空状态显示可搜范围与示例；零结果提示换词
- **仪表盘同步**：统计卡补 供应商/报价 数 + 报价卡「草稿 N 条」副链接
- **日志卡片简化**：去掉「打开日志目录」仅保留导出
- **「我的」页加入用户群卡片**：打开官网群聊页面 + 邮箱反馈（复制），不内置二维码避免误导
