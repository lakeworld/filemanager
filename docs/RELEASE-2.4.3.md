## 1.1 休眠后黑屏、无法唤醒（四个缺陷叠加修复）

- **唤醒不再提前 show**：`windowShow()` 重建窗口时不再立刻显示，改由 `ready-to-show` 渲染就绪后才显示——此前重建后先露出深蓝近黑底色空窗，加载慢/卡住即"黑屏"
- **加载底色改浅**：`#0f172a` → `#f8fafc`（与界面一致），加载期观感从"黑屏"变"加载中"
- **唤醒活性检查（唤醒机制本体）**：每次唤醒（托盘点击/最小化恢复）ping 渲染进程（2 秒超时），假死但未崩溃（不触发 render-process-gone）时自动 reload——解决"黑屏后没有任何办法恢复"
- **最小化休眠恢复自愈**：最小化 2 分钟不可见 reload 后置标记，恢复时在可见状态再校验一次活性
- **GPU 进程崩溃自动恢复**：崩溃后 1 秒 reload 主窗口一次，纳入崩溃时间窗计数（10 分钟 ≥3 次才退出，防循环）
- **诊断可查**：休眠/唤醒路径补 `[wake]`/`[sleep]` 日志；休眠定时器支持环境变量覆盖（`QIHEBOX_DESTROY_DELAY_MS` / `QIHEBOX_MINIMIZE_RECOVER_MS`），可用 10 秒完整跑休眠→唤醒循环自查

## 1.2 右键「编辑信息」→「保存元数据」无反馈

- **通用 toast**：`showToast`（成功绿 / 失败红，默认 3s 自动消失）；证书到期横幅行为不变（红色 15s）
- **保存全链路反馈**：保存成功弹「元数据已保存」，失败弹原因；保存中按钮防连点（显示"保存中..."）

## 1.3 仪表盘可点击

- **最近文件**：点击直接打开预览（与文件浏览器双击行为一致）
- **统计卡片**：产品集 / 图片 / 证书 → 跳转对应页面
- **到期提醒**：点击跳到证书库并自动按该产品集过滤（证书库新增 `?productSet=` 深链支持）
