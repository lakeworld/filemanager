### 1.1 核心修复：切换文件夹图片渲染不出来（用户反馈主问题）

- **VirtualGrid 响应式化**：网格 `count` 从一次性求值改为 getter、行内容改为响应式派生——切文件夹/断点变化时网格随数据重建（旧实现 count 冻结 + 行死切片，新文件夹内容进不了网格，观感"卡死"）
- **缩略图队列 `ThumbQueue`**：浏览请求插队优先、切文件夹时作废旧积压（`files:list` 入口自动作废）、单任务 15s 超时防全局死锁、队列上限 200——旧文件夹几百张积压不再饿死新文件夹
- **缩略图容错**：URL 经 `img.onload` 验证后才进 LRU，加载失败剔除缓存下次重试；协议响应加 `Cache-Control: immutable` 回切秒显

### 1.2 交互体验

- **单击选中 / 再点取消 / 双击打开**：文件浏览器、图包库、证书库统一（废弃 v2.4.1 的 250ms 延迟判定）；证书库不再单击即弹预览
- **右键即时可用**：右键未选中项自动先选中再出菜单；修复根因——菜单 `open` 未 `stopPropagation`，事件冒泡到 window 的关闭监听器导致菜单刚打开就被关闭
- **证书库到期徽标**：卡片显示 `到期日（剩 N 天）`，30 天内红色高亮；`loadAllCerts` 加代数守卫防切工作区竞态

### 1.3 PDF / 媒体

- **修复 dev 下 PDF 打不开**：vite 预打包给 pdfjs worker 注入 `import "/@vite/client"`，blob worker 无法解析该裸路径 → worker 加载失败 → 整份 PDF 打不开（仅 dev 复现，打包产物不受影响）。修复：`electron.vite.config.ts` 排除 `pdfjs-dist` 预打包 + dev 分支用 `?raw` 原始源码（生产构建死代码消除，体积不变）
- **视频可拖进度条**：协议层手写 Range/206 + Content-Range（旧实现 `net.fetch(file://)` 透传不回 206，`<video>` 无法 seek）
- **超大 PDF 保护**：>100MB 内嵌预览整载有 OOM 风险（Linux 1GB 堆上限），改为引导「用系统程序打开」
- **预览防泄漏**：pdfjs 加载中关闭弹窗不再泄漏 PDFDocument + worker（disposed 标志）；连开多个文件时慢返回不再覆盖当前预览（序号守卫）

### 1.4 数据安全与健壮性

- **元数据 key 重构**：`产品集/图包|证书/子文件夹/文件名`，固定 `/` 分隔符（Windows 旧 `\` key 兼容回退 + 写入懒迁移）——不同子文件夹同名文件元数据不再串号、回收站 purge 不再误删
- **批量操作部分失败聚合**：删除/移动/导入返回 `{ 成功, 失败明细 }`，单个失败不中断整体；导入重试不再产生 `_1` 重复副本；源不可读进入失败清单
- **路径安全收口**：产品集/子文件夹/文件名入参校验（防路径穿越与 Windows 非法字符）、`saveTextFile` 工作区/对话框白名单、资源管理器 PowerShell 注入修复、协议层 realpath 防符号链接逃逸
- **导入链路**：互斥锁防并发同名覆盖 + `COPYFILE_EXCL`、元数据批量落盘（消除逐文件全量重写 metadata.json）、缩略图异步生成不阻塞导入
- **崩溃自愈**：崩溃计数改时间窗（10 分钟 ≥3 次才退出，`clean-exit` 不计），杜绝「崩溃→加载成功清零→再崩溃」无限循环
- **证书提醒**：到期日期宽松解析（`YYYY/M/D`、ISO 带时间等）+ 写入归一化；已删除/外部删除的证书不再提醒；系统通知不可用时降级为应用内横幅且不误记去重；通知聚合为一条摘要 + 点击唤起窗口
- **内存与资源**：metadata 缓存按文件 mtime 失效（双机坚果云同步不再整体覆盖）、启动清理 14 天前日志、内存看门狗死代码移除、导入/预览/拖拽等窗口销毁竞态守卫

### 1.5 剪贴板

- **Windows 复制文件**：改 PowerShell `Set-Clipboard -LiteralPath`（旧 CF_HDROP 按名注册得到非预定义 15 的格式 ID，资源管理器/微信粘贴无内容）——**需 Windows 实机验证**
- **Linux 复制**：xclip 复制成功后 Promise 不再挂起（改监听 `exit`）；无 xclip 时依次回退 xsel / wl-copy，全部失败明确报错不假成功

### 1.6 测试

- 单测 123 例全绿（+13：缩略图队列 5、命名无扩展名冲突、导入整批容错、元数据隔离/懒迁移/批量写、证书日期与存在性）
- e2e 21 例全绿（+2：PDF 预览回归——生成最小合法 PDF 断言 canvas 渲染；切文件夹强断言——缩略图 src 集合与目标文件夹一致且与旧文件夹无交集）
