# 启禾文件管理 v2.5.7 发布说明

> 版本：2.5.7 · 2026-08-31 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版为 **内建笔记 + 标签域 + 剪贴板守卫 + 启禾云链路修复** 版：笔记直接在应用内编辑（所见即所得）、标签可按业务域分类、复制粘贴不再被文件路径「白拷」，并修复了启禾云请求的宿主代签拼接缺陷（部分环境下表现为 HTTP 401）。

---

## 一、内建「笔记」（Crepe 所见即所得编辑器）

- **双击即可编辑**：产品集 / 客户 / 供应商三域新增内建「笔记」文件夹，双击 .md 文件直接进入所见即所得编辑（不离开应用）
- **编辑即保存**：500ms 自动保存 + Ctrl+S 立即保存；顶栏显示保存状态（编辑中…/已保存/保存失败）；未编辑不落盘（零写入）
- **笔记工作台**：侧边栏「笔记库」入口，聚合三域最近笔记，点击直达编辑；支持选归属新建笔记
- **整包压缩可选**：产品集打包时可选择是否附带笔记（默认不带）
- **保存口径说明**：编辑器保存时按标准 Markdown 规范化输出（如 `- 列表` 归一为 `* 列表`、任务项写作 `* [ ]`），语义与内容不变，仅记法统一

## 二、标签按业务域分类

- 标签可设定业务域：文件 / 产品集 / 客户 / 供应商 / **发票** / **报价**（新）或全域通用
- 设置页按域分组展示、行内快速改域；各业务页面只显示同域标签

## 三、剪贴板守卫修复

- 修复「文件选中时 Ctrl+C 被白拷成文件路径」：输入框 / 编辑器 / 文本选区正常复制，仅无选区时复制文件路径
- Crepe 编辑器中 Ctrl+K 不再被全局搜索抢走

## 四、启禾云链路修复

- 修复宿主代签请求的 URL 双段拼接缺陷（`…/api/api/box/…` → `…/api/box/…`）：部分环境下启禾云在线请求表现为「服务拒绝访问（HTTP 401）」，本版已在宿主侧根治
- 发票 AI 识别需登录启禾云账号后使用（未登录时入口置灰并引导登录；服务端权益与额度校验为最终防线）

## 五、其他

- 表单控件统一：6 处筛选日期换用统一日期选择器；区间倒挂自动归一化
- 批量 AI 识别 → 待确认区交互沿用 v2.5.6

> 升级建议：使用笔记、标签分类或启禾云（发票 AI 识别 / 局域网协作）的用户建议升级。
