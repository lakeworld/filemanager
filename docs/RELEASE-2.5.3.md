# 启禾文件管理 v2.5.3 发布说明

> 版本：2.5.3 · 2026-08-19 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版为 **稳定性打磨版本，无新功能**：三轮打磨（后端稳定性 + Renderer 内存治理 → 找 bug 打磨 → 常驻轻壳窗口生命周期）。**普通用户可见收益：白屏类问题根治、万图工作区 Dashboard 秒开、若干数据一致性与体验修复**。

> **2026-08-19 热修（当前发布包已含）**：修复「托盘隐藏数小时后唤不醒」——旧版恢复前会先做隐藏态截图预检，长时隐藏后系统合成器休眠导致预检永远无结果，反而弹出「重试/退出」框吞掉托盘点击。已整套删除该预检机制，改为**点托盘直接开窗**（普通桌面应用语义），开窗后再做像素级白屏自检兜底；截图故障只记录日志，绝不再阻塞唤醒。托盘恢复实测 p95 35ms。

---

## 一、白屏根治：分层休眠取消 + 常驻轻壳

- **分层休眠机制整体移除**（最小化超时回收、关窗到托盘倒计时销毁）：「不可见 reload / 销毁重建 + GPU 合成表面失效」的组合是历次白屏事故的总根因（v2.4.3 起五轮自愈补丁仍有漏网），本版消除病因——关窗仅隐藏到托盘、最小化不回收，渲染进程常驻
- **常驻轻壳窗口生命周期状态机**：唤醒/崩溃/假死恢复链状态化、稳定收敛；恢复 = 直接开窗 + 开窗后白屏自检兜底（2026-08-19 热修语义，原 FrameWitness 隐藏预检已废止）
- **Windows 唤醒信号接入**（WM_POWERBROADCAST），配合 Linux 唤醒轮询兜底，跨平台统一入口
- **代价如实记录**：托盘常驻内存 295 → ~490MB（渲染进程常驻，用内存换可靠性）；开机自启不建窗的自启态 ~282MB 不变，仍是最省常驻形态

## 二、后端稳定性 + Renderer 内存治理（打磨轮）

- 共享 JSON 写路径事务化：十类台账/配置写入前严格读取，损坏先隔离备份并拒绝覆盖，杜绝并发互丢与静默覆盖
- 插件激活挂起不再拖死宿主（15s 握手超时 + 熔断幂等释放）
- 账号登录 15s 超时、心跳单飞 + 会话代数隔离、登出中止在途心跳
- 工作区切换竞态根治（索引候选会话 + 交换区按代隔离）
- 预览生命周期代际守卫：迟到的预览结果不再覆盖当前预览；列表页卸载即停止加载链

## 三、找 bug 打磨轮（六维扫描，P1 清零）

- 文件页右键「移动到…」修复（此前提交必报错）
- 切工作区文件列表即时刷新
- JSON 整档替换残留站清零（重命名/移动/回收站/标签传播并发互不丢）
- **Dashboard 首载统计万图加速约千倍**：15000 文件工作区 125ms（此前 >120s）
- 搜索加载态永久卡死修复；心跳 401 登录过期即时提示
- 另有 19 项 P2 体验/边界/一致性修复（详见 CHANGELOG）

## 四、测试与门禁

- 单测 **736** / e2e **135** / 双 tsc 零错误 / 构建通过 / 一致性套件独立口径 / 内存 soak 独立口径（2026-08-19 热修后口径：删除功能对应用例同步删除，覆盖由新故障注入 e2e 接管）
