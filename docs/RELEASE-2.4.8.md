## 一、核心修复

### 1.1 视频进度条失效（点击进度条返回起点）

- **根因**：`qihebox://file/` 协议对 `Range: bytes=0-` 开放区间按 1MB 截断返回 206，Chromium 媒体加载器视为「读到流尾」——moov 在文件尾部的大视频只拿到前 1MB 即报加载失败，进度条不可用
- **修复**：Range 一律流式完整返回请求区间（与 http 服务器语义一致）；大视频（>1MB、moov 尾部）现在可正常拖动进度条

### 1.2 休眠唤醒白屏（历史问题复发根治）

- **根因**：v2.4.3 只把加载底色从深蓝改浅色（黑屏→白屏，掩盖）；窗口可见时休眠唤醒没有任何自愈触发点（`powerMonitor` 未监听）
- **修复**：监听系统休眠恢复，分层自愈——崩溃→自动刷新；画面像素检测（GPU 表面失效白屏）→自动刷新；正常画面不打扰

- **设置页标签树折叠**：有子标签的顶层标签默认收起，点箭头展开
- **一键打包**：产品集页「打包此图包」（压缩整个产品集目录）+ 证书页「打包当前筛选」
- **反馈体系统一**：全仓 88 处原生弹窗 → 应用内 toast（成功/失败/提示三色调）+ 统一确认对话框；删除文案统一「将移入回收站，可在回收站恢复」
- **弹窗 Esc 关闭**、**窗口状态记忆**（重启恢复尺寸/位置/最大化）
