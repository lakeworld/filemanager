# 启禾文件管理 v2.5.1 发布说明

> 版本：2.5.1 · 2026-08-15 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版为 **v2.5 之上的三个增强轮**：阶段一（产品集文档文件夹 / MD 预览 / 双击分流默认应用打开）+ 阶段二（UI 打磨轮）+ 登录增强轮。**普通用户可见变化集中在文档管理与登录体验**；插件宿主能力域（customers/share）为内部版配套增量，公开协议只增不删。

---

## 一、阶段一：产品集文档（v2.5.1 F1）

- 产品集新增 **文档/** 目录（与图包/证书并列）：说明书、参数表、质检报告等文档类文件有了标准落位；`docs` 子文件夹配置沿用图包/证书同款机制
- **MD 预览**：Markdown 文件内置渲染预览（标题/列表/代码块/表格），无需外部编辑器
- **双击分流**：默认应用打开逻辑按文件类型分流（文档 → 系统默认应用，图片/证书/视频走应用内预览），右键菜单可随时「用默认应用打开」

## 二、阶段二：UI 打磨轮

- 视觉体系升级：组件底座（按钮/输入框/卡片/徽章）统一化、页面一致性修整、错误态与空态文案规范
- 侧边栏/「我的」页/插件管理页等既有页面的细节打磨（与 v2.5 视觉基线对齐全仓）

## 三、登录增强轮

- **登录链路生产实测验证**：登录 200 + 心跳 200（服务器真实链路走通）
- 修复登录态不恢复缺陷（重启后重新打开工作区即恢复）
- 会话过期提示条新增「重新登录」按钮；登录/登出操作结果 toast 反馈；删除「AI 额度」红线 4 遗留文案
- 错误如实展示（服务器 message 透传，如「登录过于频繁，请稍后再试」）

## 四、插件宿主能力域增量（内部版配套，协议只增不删）

- **customers 能力域**（`host.customer.*`）：客户档案读写 + erp_ext 写回 + 关联 + 变更事件（公开契约 `docs/PLUGIN.md` §5.5）
- **share 能力域**（`host.share.*`）：工作区只读实体视图 + 拉取写 + 元数据合并（公开契约 §5.6，getThumb 缩略图通道留 v2.7）
- 事件白名单 +3（customerCreated / customerUpdated / fileArchived）；管理页权限区展示
- 协议 v1 只增不删；API 面基线更新（`npm run api:update` 超集强制守护）

## 五、测试与门禁

- 单测 **576** / e2e **99** / 双 tsc 零错误 / 构建通过 / 一致性套件独立口径
- 内存三态实测：醒着 487-488 / 托盘常驻 294-295（过门禁；A 流复测高态 510-511/309 为环境双稳态，托盘 294-295 达标）
