# 启禾文件管理 v2.6.0 发布说明

> 版本：2.6.0 · 2026-09-23 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版是**分发形态升级**的一版：官方插件有了正式分发面（插件目录 + 登录下载 + 加密取钥），应用自己会更新了；顺带把 AI 工作台的「单据识别建档」补齐，并修掉一个长期把瞬时尖峰当回归的性能判据。

---

## 一、官方插件正式分发：插件目录 + 官方预装

- **应用内「插件目录」**：登录后直接看到官方插件（图标 / 一句话简介 / 版本 / 体积 / 权限声明），一键下载安装；有新版本时应用内提示，装完提示重启生效。
- **官方预装（离线可用）**：安装包里预带官方插件，首次启动**零操作**即可在管理页/侧栏看到；预装走的是**标准安装管线**（整包校验 + 清单校验 + 解压落盘），与手动安装完全平等：
  - 同样可停用、可卸载、可被更高版本覆盖，**不享有任何隐藏通道**；
  - 已装同版本或更高版本时**跳过**，不覆盖你自己的版本；
  - 开源自建构建不带预装目录 ⇒ 零预装条目，出包与功能不受影响。
- **插件加密分发与取钥**：官方插件包以密文分发，登录后按档位在线取钥、内存解密加载（无明文回退）；取钥失败会**明说原因和下一步**（未登录 / 需要订阅 / 校验不符 / 网络问题…），绝不静默失效——fail-closed 语义不变。
- **登录下载锁**：目录与包都要求登录态；匿名请求一律 401。

## 二、应用内更新（客户端内更新）

- **Windows（NSIS）与 Linux（AppImage）全链**：检查更新 → 后台下载（带进度）→ 退出并安装 → 自动回到新版；下载完的包**逐字节校验**后才交给安装器，校验不符即删残包并如实报错（可就地重试，不必重下）。
- **Linux deb 版不自动安装**：只提示「有新版」并给官网下载直链——这是有意为之（系统包管理器才是 deb 的正确更新路径），不是故障。
- 更新源是自有服务器的公开更新面（`latest*.yml` 申报版本与校验值），与本仓打包配置同源、有测试钉住。

## 三、AI 工作台：单据识别建档

- **多选单据一次识别**（一次最多 10 张，超过会明说拒跑而不是静默截断）：报价单、入库单、证书、发票、认不出的，自动**按类型分组**分别给出下一步；单张失败只报该张，不影响其余。
- **报价单 / 入库单** → 打开新建表单**预填**好字段，逐条核对后保存——**永不自动建档**。
- **证书** → 两次点击确认后写入证书类型与到期日（进元数据，**到期提醒**随之生效）；签发方与证书编号只进备忘摘要，不进元数据。
- **发票** → 指回原本的发票识别流程（不从这条链重复识别）。
- **认不出的** → 明说认不出，给人工建档提示。
- **看图问答 / 读文档问答**两卡随本版点亮（云端问答面已上线）；**打标**新增「允许 AI 提出新标签」开关——默认只用你已有的标签。

## 四、工程与发布链（你用不到，但决定你能多快拿到修复）

- **泄漏门禁扩容**：补四类平台令牌**形状**检测（OpenAI 形 / GitHub 形 / AWS 形 / JWT 形）；文档段示例地址的豁免从整段 /24 收紧为只放过规范示例地址本身。
- **推公开仓固定两道闸**：静态泄漏门禁 + **三路独立私密面审计留档**（凭据与身份面 / 商业与内部信息面 / 隐私数据与产物生态面），无记录直接拒推。
- **性能探针判据勘正**：懒加载路由首渲染判据统一为「5 样本次大」（升序第 4 值）——此前实现误取最大值，长期把一次瞬时尖峰当回归，是"本机绿、CI 红"一类假红的根源；阈值与基线数值一字未动。
- **版本一致性自检**：安装包版本号、更新日志、README 徽标、发布说明、安装教程同源，不一致就不出包。

## 五、已知限制（如实）

- Linux deb 不支持应用内自更新（提示 + 官网直链）。
- 官方插件目录 / 取钥 / 问答需要在应用内登录；未登录时相关入口给出中文说明并置灰。
- 本机自动化面 e2e 有 4 条**既存环境红**（系统暂停/时钟唤醒路径的显示后自检有时不武装；已用推送前基线树复跑证实与 2.6 无关，登记待专批），Windows 真机与双机（局域网）矩阵仍属人工验收项。
