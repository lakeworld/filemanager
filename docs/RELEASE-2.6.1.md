# 启禾文件管理 v2.6.1 发布说明

> 版本：2.6.1 · 2026-09-26 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版是**日常使用手感**的一版：启动能直接开你指定的盘、设置页分了页签并能一键换行业文件夹模板、回收站把「还能恢复几天」写在脸上、插件页从一行列表变成看得懂装什么；同时把几处「界面说的话和实际行为不一致」的地方对齐。

---

## 一、打开就是你要用的那个盘（默认工作区）

- **把某个工作区设为默认**：在「我的」里一键设定，之后**启动应用直接打开它**，不用每天在选盘界面点一次。
- 取消默认、或默认盘暂时不在（U 盘没插 / 网盘没同步），会**回落到最近打开**并如实说明，不会卡在空白页。
- 插件侧同时拿到一个只读的「当前工作区」接口——插件知道你在哪个盘工作，不会指错地方。

## 二、设置页分了页签，新增「文件夹模板」

- **设置页拆成四个页签**（通用 / 标签 / 文件夹模板 / 高级）：不再一条长滚动找设置；**底部共用一个「保存设置」**，切页签不丢改到一半的内容。页签地址可分享（`#/settings?tab=folders`），后退键不会在页签之间空转。
- **行业文件夹模板（8 套内置）**：电商 / 销售 / 外贸 / 医药 / 制造·五金 / 设计·广告 / 食品 / 通用——点「用这套」把图包 / 证书 / 文档 / 客户 / 供应商五张清单整体换掉；也可以「＋ 新增模板（存当前清单）」把你们自己的分类存成模板（可重命名 / 覆盖 / 删除）。顶部「当前：×××」是**算出来的**：手改任意一张清单就自动变「自定义」。
- **三条边界写在明面上**：点模板只改草稿（按「保存设置」才生效）；**只影响以后新建的实体**，已有实体盘上的文件夹一个都不动；自定义模板跟着工作区走。
- **新建产品集弹窗加了显眼引导**：直接说「文件夹名按当前模板（×××）生成」并列出会建哪些文件夹；不合你们的项目，点「设置 → 文件夹模板」当场跳过去换一套。名称输入框的示例文字也跟着模板走（电商 = 「如：夏季T恤系列」）。**老工作区默认值一字未变**，仍然是电商那套。
- 设置页底部补了**台账入口**（发票 / 报价 / 计算三行）——不用回侧栏找。

## 三、回收站：把「还能恢复几天」写在脸上

- **保留期上屏**：空态写明「删除的内容会先移到这里，30 天内可恢复；到期后应用启动时自动清理」；每条按删除时间算出**「剩余 N 天可恢复」**，到期显示「已到期，重启后自动清理」。此前界面只写「可随时恢复」，与「启动时静默清理」的实际行为不符——这是本版最该修的一处「话与做不一致」。
- **Excel 导入模板不再自带示例数据行**：示例挪进表头单元格的**批注**（鼠标悬停可见），模板本身不含数据行——以前「下载模板直接导入」会凭空多出一个「示例产品集」。
- **帮助文档的更新说明与前几版的真实能力对齐**：Windows 安装版与 Linux AppImage 版可在**应用内下载并安装**（下载期间可继续用应用，退出后自动安装并重启）；deb 版仍走官网下载。删掉了「应用内暂不提供自动安装」这类已经过时的口径。

## 四、计算页：一本本台账，不再一锅乱炖

- **左栏改成容器列表**：点「新建容器」起个名，就能把「报价核算」「装箱毛重」这类账分开放；点左栏任意一本切换，右键可**重命名 / 删除**（删除会**点明有几条记录跟着消失**）。
- 右栏只看当前这本容器，顶部加 **「全部 / 已标记」** 页签。
- **老工作区一条都不会丢**：以前记下的计算，第一次打开时自动归到一本叫「默认」的容器里，跨重启还在。

## 五、插件页：从一行列表到「看得懂装什么」

- 官方插件条目加**截图缩略图**；点行内「详情」看**大图轮播 + 功能介绍 + 权限摘要 + 该版本的更新说明**。
- **官方没写的就是没写**：没给截图⇒整块不渲染（不留空框）、单张加载失败⇒只退那一张、没写介绍/更新说明⇒如实说明，不编占位。
- 安装钮进了详情弹窗，行内与弹窗共用同一套文案判定。

## 六、工程与发布链（你用不到，但决定你能多快拿到修复）

- **插件文件选择走正规通道**：宿主新增「多选文件」对话框能力（单批上限 200，超出会明说），官方工具箱不再绕宿主内部桥——「选了图片没反应」那类问题从通道层面消失。
- **宿主内置图像引擎**：图片处理交由宿主自带的图像引擎完成（官方工具箱不再自带一套图像运行时），失败分类更准、更新应用即可获得引擎改进。
- **取钥判定与出路话术对齐**：被判「包与登记不一致」时不再暗示「重装必然解决」（重装回来还是同一份），并给第二条出路（把插件名与版本反馈给我们）。
- **官方目录条件取回**：目录响应带 ETag，未变化时 304 复用，不再每次进插件页整份重传。
- **判据侧收口（工程内务）**：把一批「改了产品码测试照绿」的判据补成真断言（回收站保留期、发票删除弹窗初值、Excel 原样导入、删除断言带错误码等），并给关键判据留下反向实验读数。

## 七、已知限制（如实）

- Linux deb 不支持应用内自更新（提示 + 官网直链）。
- 官方插件目录 / 取钥 / 云能力需要在应用内登录；未登录时相关入口给出中文说明。
- **Windows 真机链**（安装卸载 / 高 DPI / 注册表自启 / 杀软 / 真机更新链）与**双机局域网矩阵**仍属人工验收项，本版以 wine 冒烟与自动化面替代取证，未做真机目测。
- 插件页详情里的**截图素材尚未随本版上线**：首批采集需要登录态（图形码需人工过一遍），排后续批次；官方目录对还没写素材的条目**如实留白**，不拿占位图充数。
