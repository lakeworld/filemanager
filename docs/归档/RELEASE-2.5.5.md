# 启禾文件管理 v2.5.5 发布说明
> 归档时间：2026-09-01 · 归档原因：版本已被取代（发布说明保留当前版 RELEASE-2.5.7；docs-staleness-policy §三，用户批准归档）

> 版本：2.5.5 · 2026-08-24 · 开源免费（Apache-2.0）
> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版为 **账务工作流打磨版**：发票/入库卡片化 + 批量 AI 识别（保存才落盘）+ P0 归档后移（脏守卫/零孤儿）+ 报价孤儿补建 + 金额输入统一 + LAN 白名单收口。**普通用户可见收益：发票台账更好看更好筛、一次识别最多 10 张批量建档、误操作不残留孤儿文件、报价单也能筛「未登记文件」**。

---

## 一、P0 归档后移（发票 / 入库 / 报价，保存才落盘）

- **识别/选文件只暂存，点保存才归档**：新建/编辑弹窗里选本地文件或 AI 识别后，不再立即复制归档；仅确认登记时按日期归档入 `发票/年份/`、`入库/年份/`、`报价/年份/`，保存失败自动回滚本次归档副本（走回收站）
- **弹窗脏守卫**：有未保存的暂存源/预填文件/表单改动时，关闭（遮罩、Esc、取消）统一弹「放弃未保存内容？」二次确认；放弃即零落盘——**放弃新建/编辑后文件夹零残留**
- **孤儿兜底**：发票/入库新增「未建档文件」视图、报价页提示条 + 未建档视图——目录里有文件但台账无记录，即可一键补建（带文件预填新建）或删除（走回收站）

## 二、发票 / 入库卡片化（去表格）+ 批量操作

- 台账从表格改为 **VirtualGrid 卡片**：金额主视觉（千分位对齐）、号码/日期/开票方→购买方、状态徽章点击流转、悬停编辑/查看归档/删除
- **批量工具条**（勾选 ≥1 浮现）：全选可见 / 批量改状态（待报销↔已报销）/ 批量删除（二次确认）/ 批量导出 Excel
- **筛选增强**：搜索 + 状态/客户/待办 之外，新增 日期范围 / 金额范围 / 有无归档文件 三组组合筛选；已选行「已选 N · 合计 ¥X」

## 三、批量 AI 识别（插件 com.qihe.cloud v0.4.1）

- 发票页「🤖 批量 AI 识别」（**安装并启用启禾云插件后浮现**）→ 工作区文件多选面板（产品集×图包/文档/证书，一次 ≤10 张，超出提示）→ 云识别 → 「批量登记 N 张」确认 → 逐张「保存时才归档」建票
- 汇总提示「成功 N / 失败 M / 忽略 K」，失败列出文件名可重试；识别字段不全（缺号码/金额/开票方/购买方）不建档、不落盘
- 识别能力全在插件（AI 推理/凭据/网络），本体零 AI

## 四、报价页筛选对齐发票

- 搜索（单号/客户）+ 状态/客户 + 日期范围 / 金额范围 / 有无归档文件 / 台账|未建档视图 + 金额合计行

## 五、其他

- **金额输入统一（MoneyInput）**：发票/入库/报价三处金额通过滤非法字符、失焦千分位格式化（负数/小数点/超长小数截两位）
- **日期选择器增强**：年步进跳转 + 快捷芯片（今天/月初/月末/年初）+ 点击相邻月格子同步视图
- **LAN 白名单收口**（插件 com.qihe.lan v0.2.3 补丁）：传输拉到的新子文件夹自动注册（图包/证书/文档/客户全入口），面板即时可见，完成通知带「已加入白名单」
- 修复：编辑预填竞态、发票弹窗连点重复建档等一批问题（随 v2.5.4 → v2.5.5 累计）

> 宿主协议零变更（插件协议面 `api:update` 无 diff）；批量识别/云桥/AI 为插件能力，随官方插件版本升级获取。
