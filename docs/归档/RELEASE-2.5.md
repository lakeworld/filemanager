# 启禾文件管理 v2.5 发布说明
> 归档时间：2026-09-01 · 归档原因：版本已被取代（发布说明保留当前版 RELEASE-2.5.7；docs-staleness-policy §三，用户批准归档）

> 下载：官网 `https://www.qihebook.cloud/file-manager` · 源码 GitHub `lakeworld/filemanager`
> 本版为 **v2.4.9 之上的插件基础设施版本**：公开插件协议 v1 冻结 + 插件宿主 + `.qbox` 侧载 + hello 开源教学插件 + 协议测试四件套。**普通用户零变化**（「我的 → 设置 → 插件」页为空列表 + 风险横幅，官方插件索引 v2.6+ 上线）。

## 一、插件协议（v1，发布即冻结）

- 公开契约 `docs/PLUGIN.md`——**协议 v1 从此冻结，只增不删**（API 演进政策：同一大版本内仅新增，废弃标记 `@deprecated` 至少存活一个宿主大版本）
- 插件作者据此开发 `.qbox` 插件：manifest 九条校验、握手状态机、双向 API（PluginHost 白名单 / PluginRegistration）、渲染层 `window.qihebox.plugins`、IPC 通道命名、安全与信任分级、状态隔离
- 协议增量（相对 tag 版）：`syncScope`（状态同步声明）、`host.account`（登录态）、`host.files`（受限读写 + 错误码）、`host.entitlement`（权益占位恒 free）、侧载收紧（开发者模式）
- 诚实说明（协议即承诺）：CSP 响应头为形式防护（真隔离在 v2.7 `transport='process'`）；侧载 SHA-256 为记录非比对（官方索引 v2.6+ 比对）；inproc 信任模型为架构约定——文档如实写明，发现不符请提 issue

## 二、插件宿主（零插件 = 零变化）

- 主进程宿主（registry / loader / installer / host / ipc）+ preload 透传 + 渲染层（插件管理页 / 侧边栏插件分组 / 右键命令注入）
- `.qbox` 侧载安装：JSON Schema + SHA-256 记录 + zip-slip 防护 + 路径逃逸拒绝；「设置 → 插件 → 开发者模式」门控（默认关）+ 风险确认框
- 熔断：插件连续失败 3 次自动 broken（业务错误码不计），管理页展示原因与计数
- 未安装/禁用插件：零内存、零代码加载；不进 `app ready → 窗口可交互` 关键路径

## 三、hello 开源插件 2.5.5（教学样板）

- 演示三种能力：IPC（ping 往返）/ 页面（侧边栏「插件」分组）/ 右键命令（统计文件数）
- `src/plugins/hello/README.md` 完整教学：目录逐文件讲解 + 15 分钟上手（clone → 构建 → 侧载）+ 改造指引 + 契约速查
- 随发布提供 `.qbox`（官网下载区），不进安装包

## 四、插件开发者工具

- **一致性套件**：`npm run conformance -- <你的插件.qbox>`——manifest 校验 → 安装 → 握手 → 能力抽查 → 卸载，第三方插件体检（用法见 `tests/e2e/conformance/README.md`）
- **协议测试四件套**（守护"协议即承诺"，随源码开源）：API 兼容性守护（`npm run api:update` 超集强制）/ 契约对账（文档与实现双向漂移报警）/ 模糊测试（fast-check 三套）/ 一致性套件
