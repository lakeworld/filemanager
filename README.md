## 这是什么

产品图片、证书、说明书散落在微信、钉钉、邮件和各个文件夹里，要用时翻半天，发给客户还怕拿错版本——**启禾文件管理**把散落的产品资料按「产品集」归拢到一处，几秒找到、一键发给客户。

**谁适合用**：电商卖家、品牌运营、供应链销售、线下客户经理——凡是经常要给客户发产品图、发证书的人。

**怎么组织资料**：`产品集`（一个客户 / 一个产品系列 / 一个项目）→ `图包 / 证书` → 子文件夹（主图、详情页、白底图、3C、质检…）。跟着业务习惯走，不需要学新概念。

## 核心亮点

- **万图不卡**：图包库 / 证书库虚拟滚动，1 万张图列表 DOM 恒定约 40 个卡片，滚动丝滑、内存不涨
- **跟手拖出即发**：拖出去的图标就是你正在拖的那张真实图片，拖到桌面、微信、邮件即原图；选中复制后在聊天窗口 `Ctrl+V` 直接粘贴
- **拖拽导入自动归档**：图片/证书拖进去，按命名模板自动重命名、归到对应子文件夹，不用手动整理
- **证书到期提醒**：证书填上到期日，到期前 30 天在仪表盘提醒，不再错过续证
- **全局秒搜**：`Ctrl+K` 全局搜索，结果按「产品集 / 文件」分组、直接显示标签；库内可名称搜索 + 标签筛选叠加
- **托盘常驻即开即回**：关窗最小化到系统托盘，点开原样恢复（恢复实测 p95 35ms），页面与状态完整保留
- **回收站兜底**：删除先进回收站，30 天内可恢复，标签、备注、缩略图原样找回
- **工作区即文件夹**：所有资料就是一个普通文件夹，整个拷到另一台电脑就能接着用；放进坚果云 / OneDrive / NAS 即可多机共享

## 功能详解

- **产品集**：按客户 / 产品系列 / 项目组织资料；支持标签、备注、搜索与标签筛选；空产品集可重命名；删除进回收站
- **图包与视频**：拖拽导入图片与视频，按命名模板自动归档；图片 + 视频可混存，视频自动抓帧生成缩略图、点击即预览播放
- **证书**：导入 PDF 或图片证书（3C / 质检 / 专利…）；可填证书类型、到期日、标签、备注；到期前自动提醒
- **预览**：图片、PDF、视频本地预览；PDF 支持连续滚动、文字选中复制、全文搜索、缩放 40%–400%、跳页
- **多选与批量**：勾选卡片后批量复制、打标签、压缩分享、定位、重命名、删除；右键同样生效
- **压缩分享**：选中文件流式打包成 zip（实时进度、可随时取消），同一产品集自动命名 `产品集名_分享.zip`；上限 4GB / 65535 个文件；右键 zip 可直接解压
- **外发**：复制选中到剪贴板，微信 / 钉钉 `Ctrl+V` 粘贴原图；或在文件夹中显示后直接拖进聊天窗口
- **搜索**：全局搜索（`Ctrl+K`）+ 图包库 / 证书库内搜索，均可与标签筛选叠加
- **回收站**：删除的内容先进回收站，保留 30 天；可恢复（回到原位置，标签备注原样）或彻底删除
- **系统托盘**：关窗最小化到托盘后台常驻，点开即原样恢复；失焦 30 秒自动清理图像解码缓存
- **账号登录（可选）**：登录仅上报匿名活跃统计，不登录完全不影响任何本地功能；登录服务地址由安装包随包携带，可自建覆盖
- **数据与备份**：文件、配置、元数据全部在工作区文件夹内，无隐藏依赖；定期备份 = 复制整个文件夹

## 稳定与性能

- **白屏与托盘冻结根治**（v2.5.3）：取消后台休眠机制，窗口常驻，托盘点击即开窗，不再有"唤不醒"
- **万图 Dashboard 秒开**：15000 文件工作区首页统计 125ms（此前超过 120 秒）
- **数据写入事务化**：并发操作互不丢失，损坏先隔离备份、拒绝覆盖
- 内存如实说明：托盘常驻约 490MB（换取即开即用与唤醒可靠）；开机自启不建窗时约 285MB，是最省常驻形态

## 开发者

技术栈：Electron + TypeScript + SolidJS + Tailwind CSS（Windows / Linux 桌面应用）。

- **理念**：本地优先、工作区自包含（文件 + 配置 + 元数据同一文件夹），无数据库，纯 JSON 持久化
- **插件体系**：v2.5 起公开插件协议（API_VERSION=1，冻结只增不删），教学插件 15 分钟上手 → [docs/PLUGIN.md](docs/PLUGIN.md)
- **登录服务地址**：应用内置可选账号登录（仅匿名活跃统计，不登录不影响任何本地功能）。源码不写死服务器地址，地址由安装包随包携带（`resources/server.json`）；自建部署可在应用数据目录放 `server.json`（`{"apiBase": "https://your-server/api"}`）覆盖
- **数据兼容性**：工作区数据格式与 v1.x（Wails 版）完全兼容，零迁移直接打开

```bash
npm install          # 安装依赖（.npmrc 已配置国内镜像加速）
npm run dev          # 开发模式（热更新）
npm test             # 单元测试（vitest，736 用例）
npm run test:e2e     # 端到端测试（Playwright，135 用例）
npm run build        # 构建三段产物到 out/
npm run build:linux  # 打包 Linux（AppImage + deb）
npm run build:win    # 打包 Windows（NSIS）
```

构建说明见 [BUILD.md](BUILD.md)；性能基线公开维护于 [docs/PERF.md](docs/PERF.md)。环境要求：Node.js 20+。
